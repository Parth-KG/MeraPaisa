This page is a signpost. Everything in the link stays on your phone.

If you have Mera Paisa installed, open this link from the message you were sent and it will go straight into the app. If it opened this page instead, Android has not yet learned to route these links. Copy the whole message, then in Mera Paisa tap Settings → Record an update link and paste it.

If you do not have it yet:

  1. Install Mera Paisa from the link below.
  2. Copy the whole message someone sent you.
  3. Open Settings → Record an update link and paste it.

Why this page cannot read your ledger. The update travels in the part of the link after the #. Browsers never send that to a server, so the amounts, names and notes in it are never transmitted anywhere: not to GitHub, not to anyone. This page is plain HTML with no scripts and no analytics; it only ever sees that you asked for /MeraPaisa/s.

One thing worth knowing. Anyone can make one of these links, and nothing in them proves who sent it. Mera Paisa shows you every amount before it records anything, and never writes to your ledger without you tapping to confirm. Only accept an update you were expecting.
